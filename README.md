#### [⚡ LLM Tokenizer Arena & Context Inspector](https://huggingface.co/spaces/gitmoney313/llm-tokenizer-arena)

An interactive workbench for analyzing, benchmarking, and visualizing tokenization, chat templates, and KV-cache memory footprints across modern open LLMs (Qwen 2.5, Llama 3.2, Gemma 2, DeepSeek, and Mistral).

- 🔍 **Tokenizer Inspector**: Token chips with visual byte and character metrics.
- 📊 **Compression Arena**: Side-by-side compression efficiency benchmarks.
- 💬 **Chat Template Delimiters**: Raw prompt formatting inspector.
- 🧮 **KV-Cache Sizer**: GPU VRAM compatibility calculator for 128k context lengths.
